A flexible plan for learning [[Java]] while working full-time. Estimated duration: **8–12 weeks**

---

## 🌱 Phase 1: Core Java & OOP (Weeks 1–3)

**Goal**: Understand Java syntax, data types, control flow, methods, and **[[Java OOP|OOP]]** fundamentals.

### ⏱ Weekly Time: 8–10 hours

- 📘 **Read**:
  - *Head First Java* by Kathy Sierra (Ch. 1–5)
  - Or follow: [JetBrains Academy – Java Basics](https://www.jetbrains.com/academy/)
- 🎥 **Watch**: [BroCode Java Full Course](https://www.youtube.com/watch?v=xk4_1vDrzzo)
- 👨‍💻 **Practice**: [Exercism – Java Track](https://exercism.org/tracks/java)

### ✅ Topics:
- Variables, Data Types, Conditionals
- Loops, Methods, Arrays
- Classes, Constructors
- Encapsulation, Inheritance, Polymorphism

### 🛠 Project Idea:
**Student Management CLI App**  
> Add, remove, and list students using OOP concepts

---

## 🧠 Phase 2: Collections, Exceptions, Files (Weeks 4–5)

**Goal**: Learn Java’s standard library and error handling

### ⏱ Weekly Time: 8–10 hours

- 🎥 [Java Collections Crash Course – Amigoscode](https://www.youtube.com/watch?v=hf8xM65iKzs)
- 📘 Java Docs on:
  - [`ArrayList`](https://docs.oracle.com/javase/8/docs/api/java/util/ArrayList.html)
  - [`HashMap`](https://docs.oracle.com/javase/8/docs/api/java/util/HashMap.html)
  - [`Set`](https://docs.oracle.com/javase/8/docs/api/java/util/Set.html)

### ✅ Topics:
- Collections (`List`, `Map`, `Set`)
- Generics
- Try/Catch, Exception Handling
- File I/O (`File`, `BufferedReader`, `BufferedWriter`)

### 🛠 Project Idea:
**Note-Taking App**  
> CLI-based app storing notes to text files

---

## 🚀 Phase 3: Build Real Apps with Java (Weeks 6–7)

**Goal**: Apply Java in real-world app development

### ⏱ Weekly Time: 10 hours

- 🔧 Tools: IntelliJ IDEA + Maven or Gradle
- 🎥 [Spring Boot Crash Course – Amigoscode](https://www.youtube.com/watch?v=9SGDpanrc8U)
- 📘 [Spring Boot Docs](https://spring.io/projects/spring-boot)

### ✅ Topics:
- Spring Boot Basics
- REST API with Controllers
- DTOs, Entities, Services
- JPA + H2/PostgreSQL

### 🛠 Project Idea:
**Book Library REST API**  
> CRUD operations with in-memory or real DB

---

## 📦 Phase 4: Intermediate Concepts & Testing (Weeks 8–10)

**Goal**: Learn modern Java techniques and testing

### ⏱ Weekly Time: 8–10 hours

- 📘 Optional Read: *Effective Java* by Joshua Bloch
- 🎥 [Java Streams & Lambdas](https://www.youtube.com/watch?v=t1-YZ6bF-g0)

### ✅ Topics:
- JUnit & Testing
- Dependency Injection (Spring)
- Streams & Lambdas
- Java Code Best Practices

### 🛠 Project Idea:
**Extended API**
> Add user auth, pagination, or testing to existing API

---

## 🧩 Bonus / Ongoing

- 🧠 [LeetCode Java Problems](https://leetcode.com/problemset/all/?difficulty=Easy&listId=wpwgkgt)
- 🔍 [TheAlgorithms/Java](https://github.com/TheAlgorithms/Java)
- 📱 Consider learning Android (Kotlin) later
