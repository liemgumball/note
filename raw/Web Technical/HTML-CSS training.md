## PR title convention:

- Bugfix: `Bugfix / Fix some bug that was very hard to track down`
- Feature: `Feature / New cool input for recipe`
- Hotfix: `Hotfix / Fix that broken thing in production`

## **What Is CSS @import And Why Can It Slow Down Websites?**

Most CSS files are [**render-blocking resources**](https://www.debugbear.com/blog/render-blocking-resources), which means the browser has to download them before it can show the user any content.

When multiple stylesheets are added without `@import` (by using link tags in the HTML instead), the browser can download them in paralle

> CSS @import rules can slow down your website by causing sequential request chains.  
> [https://www.debugbear.com/blog/avoid-css-import](https://www.debugbear.com/blog/avoid-css-import)
