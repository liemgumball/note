# 📅 Web Development Beginner Course (Weeks 1–12)

## 🧑‍🎓 Student Level: Absolute Beginner

**Duration**: 6–9 months (2 sessions/week)

**Focus**: Front end Development with HTML, CSS, [[JavaScript]], and [[React]]

---

## Phase 1: Web Basics (Weeks 1–4)

### Week 1: Introduction to the Web & HTML Basics

- How the web works (client, server, browser)
- What is HTML?
- Tags, elements, attributes
- Basic structure of a web page (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Build: Simple "Hello World" web page

### Week 2: HTML Deep Dive + First Project

- Semantic HTML: `<header>`, `<footer>`, `<nav>`, `<section>`, etc.
- Lists, tables, forms
- Links and images
- Build: Personal bio page with contact form

### Week 3: CSS Fundamentals

- Inline, internal, external CSS
- Selectors, classes, IDs
- Colors, fonts, spacing, borders, sizing
- Box model

### Week 4: CSS Layouts

- Display types (block, inline, inline-block)
- Positioning
- Flexbox basics
- Responsive design with media queries
- Build: Responsive landing page

---

## Phase 2: JavaScript Fundamentals (Weeks 5–8)

### Week 5: Intro to JavaScript

- JS syntax & where to write it
- Variables: `var`, `let`, `const`
- Data types
- Operators
- `console.log()` & debugging basics

### Week 6: Conditions & Loops

- `if`, `else`, `else if`, `switch`
- Comparison & logical operators
- Loops: `for`, `while`, `do...while`
- Practice: Simple number guessing game

### Week 7: Functions & Scope

- Function declaration & expression
- Parameters, arguments, return values
- Scope: global vs. local
- Arrow functions

### Week 8: Arrays & Objects

- What are arrays? Access, loop, modify
- Common methods: `push`, `pop`, `shift`, `slice`
- Objects: keys, values, accessing properties
- Build: Basic To-Do List app (JS only, no framework)

---

## Phase 3: DOM & Interactivity (Weeks 9–12)

### Week 9: [[DOM]] Basics

- What is the DOM?
- Selecting elements (`getElementById`, `querySelector`)
- Changing content & styles
- DOM Tree, `innerText` vs. `innerHTML`

### Week 10: Events & Form Handling

- `addEventListener`
- Event types: click, input, submit
- Preventing default behavior
- Accessing form values

### Week 11: Practice & Mini Project

- Combine DOM + JS logic
- Build: Quiz App or Tip Calculator
- Focus on debugging, organizing code

### Week 12: Recap + GitHub & Hosting

- Review of HTML/CSS/JS
- Intro to Git & GitHub
- Publish mini projects using GitHub Pages

---

# 📅 Web Development Beginner Course (Weeks 13–24)

## Phase 4: Git, GitHub, and React Fundamentals (Weeks 13–20)

### Week 13: Git & GitHub Essentials

- What is version control?
- Basic Git commands: `init`, `add`, `commit`, `status`, `log`
- Pushing to GitHub
- GitHub Pages deployment
- Practice: Upload previous projects

### Week 14: Intro to React

- What is React? Why use it?
- Setting up with Vite
- Components & JSX
- `props` and reusability
- Build: Profile card component

### Week 15: State and Events

- `useState` hook
- Handling input & button clicks
- Simple interactivity
- Build: Counter app + color picker

### Week 16: Conditional Rendering & Lists

- `if` in JSX, ternary operators
- Rendering lists with `.map()`
- `key` prop explanation
- Build: Dynamic to-do list

### Week 17: Forms & Controlled Components

- Form inputs in React
- Controlled vs uncontrolled components
- Handling form submission & validation
- Build: Sign-up form UI

### Week 18: useEffect & Side Effects

- What is `useEffect`?
- Fetching data from an API
- Loading & error states
- Build: Weather or Pokémon API viewer

### Week 19: Routing with React Router

- Setting up React Router
- Routes, Links, `useParams`
- Nested routes and 404 pages
- Build: Multi-page blog UI

### Week 20: Project Week #1

- Choose 1:
    - Mini blog app (localStorage)
    - Simple task manager with CRUD
- Apply state, routing, and component composition
- Git + GitHub required

---

## 🛠 Phase 5: Backend Basics with Node.js + Express (Weeks 21–24)

### Week 21: Intro to [[NodeJS|Node.js]]

- What is Node.js?
- Running JS outside the browser
- Using `npm`
- Intro to Express.js

### Week 22: Creating a REST API

- Routing in Express
- HTTP Methods (GET, POST, PUT, DELETE)
- Sending and receiving JSON
- Build: Simple notes API

### Week 23: Connecting Frontend with Backend

- CORS, fetch requests from React
- Connecting React app to backend API
- Storing and displaying data
- Build: To-do app (React + Express)

### Week 24: Project Week #2

- Capstone Project (React + Express):
    - Ideas: Job board, Expense tracker, Recipe app
    - Full CRUD with backend
